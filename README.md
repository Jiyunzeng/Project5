## ⭐ 담당 기능 핵심 로직 및 구현 상세

### 1. TF-IDF 기반 뉴스 검색 랭킹 구현
기존의 키워드 포함 여부 중심 검색 방식은 연관도가 낮다는 한계가 있었습니다. 이를 해결하기 위해 TF-IDF 가중치와 코사인 유사도(Cosine Similarity)를 활용한 랭킹 시스템을 구축

**동작 흐름**: 검색 조건을 전달받아 뉴스 데이터를 조회한 뒤,
제목 및 본문 텍스트를 기반으로 TF-IDF 벡터화 → 유사도 점수 산출 및 정렬  
**성과**: 단순 키워드 일치가 아닌, 문맥적 연관성이 높은 뉴스를 상위에 노출하여 검색 정확도를 개선

<details>
<summary><strong>🔍 코드 보기</strong></summary>

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

vectorizer = TfidfVectorizer(
    max_features=1000,
    lowercase=False,
    token_pattern=r"\S+"
)
tfidf_matrix = vectorizer.fit_transform([query_tokens_str] + doc_tokens)

query_vec = tfidf_matrix[0:1]
doc_vecs = tfidf_matrix[1:]

scores = cosine_similarity(query_vec, doc_vecs)[0]
```
</details>

### 2. 검색 정확도 향상을 위한 점수 보정 로직 (Heuristic Scoring)
TF-IDF 유사도 점수만으로는 실제 검색 결과의 체감 정확도가 충분하지 않다고 판단하여,
뉴스 텍스트의 위치 정보를 활용한 점수 보정 로직을 추가로 적용

**제목 가중치**: 검색어가 뉴스 제목에 포함된 경우,
제목 내 등장 위치를 기준으로 추가 점수를 부여  

**본문 키워드 근접도(Proximity)** : 
여러 검색 키워드가 본문 내에서 가까운 위치에 등장할 경우,
키워드 간 최소 거리(min_gap)를 기준으로 가산점을 적용  


<details> <summary><strong>🔍 코드 보기</strong></summary>
    
```python
# 1) 제목 위치 기반 가중치 강화
pos_title = title_lower.find(q_lower)
if pos_title != -1:
    title_pos_score = max(0.05, 0.20 * (1 - pos_title / max(len(title_lower), 1)))
    score += title_pos_score

# 2) 본문 키워드 근접도(Proximity) 점수
if len(positions) >= 2:
    positions.sort()
    min_gap = min(positions[i+1] - positions[i] for i in range(len(positions)-1))
    proximity_score = max(0.0, 0.15 * (1 - min_gap / 80))
    score += proximity_score
```
</details>


### 3. 데이터 자산화를 위한 검색 로그 저장 구조
TF-IDF 검색 요청이 발생할 때마다
검색어와 검색 시점을 MongoDB에 로그로 저장하는 기능을 구현

- 검색 API 호출 시 SearchLog 객체 생성

- 검색어(keyword)와 검색 시점(timestamp)을 설정

- searchLogRepository.save()를 통해 MongoDB에 저장

<details> <summary><strong>🔍 코드 보기</strong></summary>

```Java
// NewsSearchController.java
@GetMapping("/search-tfidf")
public List<Map<String, Object>> searchWithTfidf(@RequestParam("q") String query) {
```

### 4. MongoDB Aggregation 기반 인기 검색어 기능
저장된 검색 로그를 활용하여 최근 24시간 동안 가장 많이 검색된 키워드를 실시간으로 집계하여 제공하는 기능을 구현

**동작 흐름**: 특정 시간 기준(timestamp ≥ sinceDate)으로 로그 필터링 → keyword 기준 그룹화 후 검색 횟수 집계 → 검색 횟수 기준 내림차순 정렬 → 상위 5개의 검색어 추출

**성과**: 사용자가 현재 시장의 주요 이슈를 직관적으로 파악하도록 유도

<details> <summary><strong>🔍 코드 보기</strong></summary>

```Java
// NewsServiceImpl.java
public List<Map<String, Object>> getTrendingKeywords(int hours) {
    LocalDateTime since = LocalDateTime.now().minusHours(hours);
    Date sinceDate = Date.from(since.atZone(ZoneId.systemDefault()).toInstant());

    // MongoDB Aggregation 파이프라인 구성
    Aggregation agg = Aggregation.newAggregation(
        Aggregation.match(Criteria.where("timestamp").gte(sinceDate)), // 시간 필터
        Aggregation.group("keyword").count().as("count"),              // 그룹화 및 카운트
        Aggregation.sort(Sort.Direction.DESC, "count"),                // 정렬
        Aggregation.limit(5)                                           // TOP 5 추출
    );

    return mongoTemplate.aggregate(agg, "search_log", Map.class).getMappedResults();
}
```
</details>

### 5. 실시간 자동완성 검색어 구현
사용자가 검색어를 입력할 때,
MongoDB에 저장된 검색어 데이터를 기반으로
부분 일치 자동완성 검색어를 제공하는 기능을 구현

- regex(query, "i")를 사용하여 대소문자 구분 없는 부분 일치 검색 적용
- 결과 개수를 limit(10)으로 제한하여 조회
- 조회된 결과에서 검색어 문자열만 추출하여 반환

**성과**: 검색 입력 편의성을 높이고 원하는 검색어 도달 시간 단축

<details> <summary><strong>🔍 코드 보기</strong></summary>

```Java
// NewsServiceImpl.java
public List<String> getAutocompleteSuggestions(String query) {
    Query searchQuery = new Query();
    // Regex를 활용한 대소문자 무시 부분 일치 검색
    searchQuery.addCriteria(Criteria.where("term").regex(query, "i")); 
    searchQuery.limit(10); 

    List<NewsTerm> results = mongoTemplate.find(searchQuery, NewsTerm.class, "news_terms");
    return results.stream().map(NewsTerm::getTerm).collect(Collectors.toList());
}
```
</details>
